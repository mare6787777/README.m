# 🚀 AI-Powered Customer Insights Platform

**A Serverless, Scalable Contact Intelligence System**

This project showcases a cloud-based data insights platform that uses modern AWS tools to analyze customer feedback, visualize trends, and prepare for scalable real-time insights.

---

## 📁 Project Structure

customer-insights-data-viz/  
├── architecture/ # Cloud architecture and infrastructure  
├── data/ # Raw and cleaned customer feedback data  
├── diagrams/ # System diagrams (architecture, data flow)  
├── lambda/ # Serverless functions (Lambda)  
├── outputs/ # Generated results (charts, logs, etc.)  
├── sample-data/ # Sample CSVs for testing/demo  
├── scripts/ # Data cleaning, sentiment, and chart scripts  
├── tests/ # Placeholder for future tests  
├── requirements.txt # Python dependencies  
└── README.md # Project overview  

---

## 🌐 Cloud Stack

- **AWS S3**: Data storage  
- **AWS Lambda**: Serverless data processing  
- **AWS Athena**: Querying structured data  
- **Amazon QuickSight**: Visualizing customer sentiment  

---

## 🧠 Features

- Upload customer feedback and run analysis  
- Sentiment classification (positive/neutral/negative)  
- Generate charts and dashboards (WIP)  
- Serverless and scalable design
